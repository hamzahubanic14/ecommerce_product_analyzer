# E-Commerce Product Analyzer

A small Python CLI project I built to refresh my Python fundamentals and regain confidence after a longer break from programming.

## What it does

Reads product data from JSON and calculates:

* Average, highest and lowest price
* Total stock
* Inventory value
* Average rating
* Products by category

## Concepts

Python, REST API, JSON, functions, lists, dictionaries, modules, type hints, CLI arguments, exception handling, input validation.

## Structure

```text
main.py          # CLI and error handling
analyzer.py      # analysis functions
products.json    # dataset
```

## What I learned

I worked with API/JSON data, `sys.argv`, modules and imports, `try/except`, validation, and basic data processing.

I also dealt with API connection errors, missing files, invalid JSON, incorrect data structure, and issues caused by test code running during imports.

## Workflow

```text
API → JSON → Python → Analysis → CLI
```
